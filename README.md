# ASR Project: Russian -> Polish

A simple course-project skeleton for comparing methods of Russian speech translation into Polish.

## Main idea
- compare how different pretrained models deal with our custom data -> russian tongue twisters 
- choose the best model to deal with the provided data
- crate a small pipeline with transaltion to polish & ui with the best selected model

## Installation
```bash
python -m venv .venv
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

- running with UI -> app.py
```bash
streamlit run src/app.py
```

```bash
python main.py
```
