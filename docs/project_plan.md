# Project plan (4 weeks)

## Week 1
- Collect and validate tongue twister list.
- Record pilot samples from 1-2 speakers.
- Finalize manifest format and annotation policy.

## Week 2
- Implement baseline cascade pipeline.
- Run initial baseline on a small subset.
- Verify evaluation pipeline end-to-end.

## Week 3
- Implement integrated speech translation pipeline.
- Run both approaches on the same test subset.
- Track runtime and robustness under added noise.

## Week 4
- Full evaluation and error analysis.
- Prepare report figures/tables.
- Build short side-by-side demo for presentation.
